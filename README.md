## ✨ О проекте

**Sketch** — мобильное приложение для сотрудников книжных магазинов, которое превращает рутинный учет комиксов и манги в удобный, наглядный и автоматизированный процесс.

Это не просто каталог товаров. Это полноценная система управления торговым пространством, которая позволяет визуализировать расположение стеллажей, контролировать физическую вместимость полок и быстро размещать новые поступления.

> 🎯 **Главная идея:** каждая книга имеет свое физическое место, каждый сантиметр полки учитывается, а размещение товара становится максимально простым.

## 🚀 Возможности

### 🗺️ Интерактивная карта магазина
- Визуальное представление торгового зала в 2D.
- Создание и размещение стеллажей.
- Масштабирование и перемещение карты (Zoom & Pan).
- Привязка объектов к сетке для точного позиционирования.

### 📏 Физический учет с точностью до миллиметра
- Учет реальной толщины каждого экземпляра.
- Автоматический расчет занятого пространства.
- Контроль свободного места на полках.
- Защита от размещения книг, которые физически не помещаются.

### 📖 Умный каталог и сканирование
- Поиск книг по ISBN.
- Автоматическая загрузка обложек и габаритов.
- Интеграция с BiblioNIK и Google Books API.
- Разделение сущностей на **Titles** (издания) и **Copies** (физические экземпляры).
- Поддержка нескольких копий одного издания.

### 🧠 Умные рекомендации
При добавлении новой книги Sketch анализирует:
- Серии и циклы;
- Авторов;
- Издательства.

На основе этих данных система предлагает наиболее подходящее место для размещения книги.

### ⚡ QuickScan — быстрое размещение
Специальный режим для работы непосредственно в торговом зале.

**Как это работает:**

1. Сканируешь штрихкод книги.
2. Наводишь камеру на QR-код нужной полки.
3. Sketch автоматически связывает экземпляр с выбранным местом.

Идеально подходит для быстрой разгрузки коробок с новыми поступлениями.

### 🗄️ Управление полками
- Создание полок с индивидуальными размерами.
- Назначение тематик: Marvel, Манга, DC и другие.
- Перемещение полки вместе со всем содержимым на другой стеллаж.
- Контроль вместимости и свободного пространства.

### 🔲 Генерация QR-кодов
- Автоматическое создание QR-меток для полок.
- Подготовка кодов к печати.
- Пакетная генерация и печать непосредственно через браузер.

## ⚙️ Архитектура системы

Sketch построен вокруг иерархической модели физического пространства магазина.

```text
🏬 Store
 └── 🗄️ Shelves (Стеллажи)
      └── 📚 Levels (Полки)
           └── 📖 Copies (Экземпляры книг)
                └── 📏 Physical Dimensions
                     ├── Thickness
                     ├── Height
                     └── Depth
```

### 📐 Принцип физического учета

Каждый физический экземпляр книги хранит собственные габариты.

Система автоматически суммирует толщину всех книг, размещенных на полке, и сравнивает результат с ее фактической длиной.

**Логика контроля вместимости:**

```text
Свободное место = Длина полки − Суммарная толщина книг
```

| Результат | Состояние |
|:---|:---|
| Остаток > 0 | 🟢 Есть свободное место |
| Остаток = 0 | 🟡 Полка заполнена |
| Остаток < 0 | 🔴 Превышена вместимость |

### 📦 Учет нескольких экземпляров

Издания (Titles) и физические экземпляры (Copies) разделены на самостоятельные сущности.

Например, магазин может иметь одно издание манги в количестве 10 экземпляров. При этом каждый экземпляр учитывается отдельно — его можно перемещать, продавать и размещать независимо от остальных.

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Takeshka13/my-comics-app.git
cd my-comics-app
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка окружения

Создай файл `.env` в корне проекта:

```env
EXPO_PUBLIC_SUPABASE_URL=твой_url
EXPO_PUBLIC_SUPABASE_ANON_KEY=твой_ключ
```

Укажи собственные ключи проекта Supabase.

### 4. Запуск приложения

```bash
npx expo start
```

Отсканируй появившийся QR-код через **Expo Go** на Android или iOS.

### 5. Сборка APK (Android)

Для создания релизной версии используется EAS Build:

```bash
eas build -p android --profile preview
```
